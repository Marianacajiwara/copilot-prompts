## 🚀 PROJETO DE PORTFÓLIO  

**PROJETO:** Sistema de Catálogo de Produtos  

**O QUE FAZER:**  
Construir uma aplicação web que permita cadastrar, listar e buscar produtos, com front-end em JavaScript e back-end em C# ASP.NET Core.  

**ENTREGÁVEIS:**  
- Página de cadastro de produtos  
- Página de listagem com busca  
- Banco de dados conectado e funcional  

**CRITÉRIOS DE ACEITAÇÃO:**  
- Interface responsiva  
- CRUD completo (Create, Read, Update, Delete)  
- Deploy funcionando online  

**DICA:** Use o Entity Framework para facilitar a integração com o banco de dados.  

---

## 💬 ROTEIRO DE ENTREVISTAS  

**PERGUNTA 1:** O que é HTML e para que serve?  
**COMO RESPONDER:** Explicar que é a linguagem de marcação usada para estruturar páginas web.  

**PERGUNTA 2:** Qual a diferença entre front-end e back-end?  
**COMO RESPONDER:** Front-end é a interface visível ao usuário, back-end é a lógica e dados por trás da aplicação.  

**PERGUNTA 3:** O que é uma API?  
**COMO RESPONDER:** É um conjunto de endpoints que permitem comunicação entre sistemas e aplicações.  

**PERGUNTA 4:** Explique o conceito de orientação a objetos.  
**COMO RESPONDER:** É um paradigma que organiza código em classes e objetos, facilitando reuso e manutenção.  

**PERGUNTA 5:** Como você versiona seus projetos?  
**COMO RESPONDER:** Explicar uso de Git, commits claros e branches para organizar o desenvolvimento.
